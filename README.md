# soccer-watch
A Mac/iPad/iPhone/Apple Watch logging tool for soccer

# ⚽️ Soccer-Watch Shortcut

Soccer-Watch is an Apple Shortcut designed for quick voice capture on Apple Watch.  
Raise your wrist, speak, and instantly log coaching ideas, drills, or lore into Notes or Reminders.

---

## 🚀 Features
- Dictate ideas directly from Apple Watch
- Save entries into **Notes** or **Reminders**
- Auto-tag with date/time for context
- Syncs across iPhone, iPad, and Mac via iCloud

---

## 📥 Installation

1. **Get the Shortcut**  
   [Install Soccer-Watch via iCloud](https://www.icloud.com/shortcuts/11010c2d88334854bec0618051ce15f5)

2. **Enable on Apple Watch**  
   - Open the Shortcuts app on iPhone  
   - Tap the shortcut → Settings → **Show on Apple Watch**

3. **Optional Siri Phrase**  
   - In Shortcut settings, add a phrase like:  
     `Log soccer idea`
